PASSOS PARA PUBLICAR NO GITHUB

1. Abra o repositório público já criado:
   https://github.com/DanielleSimeao/figuras-lineamento-tiete-raa-2026

2. Clique em "uploading an existing file" (ou Add file > Upload files).

3. Envie o README.md, o CITATION.cff, o index.html, o arquivo logo-prh-anp.webp
   e as nove imagens diretamente para a raiz do repositório. Todos os arquivos
   devem ficar no mesmo nível, sem uma subpasta chamada "figuras".

4. Confira se as nove imagens aparecem no README e se o visualizador permite
   navegar da Figura 1 à Figura 9.

4.1 Para publicar o visualizador como página, abra Settings > Pages, escolha
    "Deploy from a branch", selecione a branch main e a pasta /(root). Após a
    publicação, o endereço esperado será:
    https://daniellesimeao.github.io/figuras-lineamento-tiete-raa-2026/

5. Crie uma versão (Release), por exemplo "v1.0 — RAA PRH-ANP 2026".

6. Para obter uma citação permanente, conecte o repositório ao Zenodo e gere
   um DOI para a Release. Depois, substitua no resumo o link do GitHub pelo DOI
   ou mantenha ambos.
